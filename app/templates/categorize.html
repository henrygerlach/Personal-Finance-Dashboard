How rules work

A rule files a transaction by matching text in its booking line, and optionally its process code.

Parts of a rule

  • Substring — a phrase that must appear in the booking text. Enter a number instead to match the first n words of this transaction's booking text.
  • Process — the Vorgang code. Leave it off to match any process.

Order matters

Rules are evaluated in the order they were created; the first match wins.
